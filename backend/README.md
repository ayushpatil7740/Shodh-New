# Shodh Backend (Node.js & Express API)

## 🚀 How to Run Backend:
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
3. Runs on: `http://localhost:5000`
4. Health check: `http://localhost:5000/api/health`

*Features zero-config embedded JSON storage (no external database needed).*
