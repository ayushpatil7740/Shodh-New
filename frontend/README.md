# Shodh Frontend (React + Vite + Tailwind CSS)

## 🚀 How to Run Frontend:
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
3. Open: `http://localhost:5173`

## 🌐 Deploying to Netlify / Vercel:
- Build command: `npm run build`
- Publish directory: `dist`
